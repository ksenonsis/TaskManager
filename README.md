# 📋 Менеджер задач (Task Manager)

Простое Windows-приложение на C# (.NET 8, WinForms) для управления задачами.

---

## 🚀 Как открыть и запустить в Visual Studio

### Требования
- Windows 10 или 11
- Visual Studio 2022 (Community — бесплатная версия)
- В установщике Visual Studio должен быть выбран компонент:
  **«Разработка классических приложений .NET»**

---

### Шаги:

1. **Распакуй архив** в любую папку, например `C:\Projects\TaskManager`

2. **Открой Visual Studio 2022**

3. На стартовом экране нажми **«Открыть проект или решение»**
   *(или в меню: Файл → Открыть → Проект/решение)*

4. Найди файл **`TaskManager.sln`** в папке проекта и открой его

5. Нажми **F5** (или зелёную кнопку ▶ «Запуск») — проект соберётся и запустится!

---

## 🔧 Что делает приложение

- ➕ **Добавление задач** — название, описание, приоритет, статус, дедлайн
- ✏️ **Редактирование** — двойной клик или кнопка «Изменить»
- ✅ **Отметить выполненной** — одна кнопка
- 🗑️ **Удаление** задач с подтверждением
- 🔍 **Поиск** по названию и описанию
- 🔽 **Фильтрация** по статусу (Новая / В работе / Выполнена)
- Цветовая подсветка по приоритету

---

## 📁 Структура файлов

```
TaskManager/
├── TaskManager.sln          ← открывать в Visual Studio
└── TaskManager/
    ├── Program.cs           ← точка входа (запуск)
    ├── TaskItem.cs          ← класс одной задачи
    ├── TaskCollection.cs    ← список задач (логика)
    ├── MainForm.cs          ← главное окно
    ├── AddTaskForm.cs       ← форма добавления/редактирования
    └── TaskManager.csproj   ← файл проекта
```
